Aplicación web de alquiler de vehículos pensada como producto genérico para cualquier negocio de alquiler. Tiene dos áreas:

1. Área pública (clientes): catálogo digital de vehículos disponibles para alquiler y formulario de reserva.
2. Dashboard de administración: acceso exclusivo para empleados del negocio. Permite gestionar vehículos (con todos sus detalles), reservas y estados.

# STACK
- Frontend: React 
- Backend: Node.js + Express
- Base de datos: MySQL + Sequelize
- Autenticación: JWT con roles (CLIENTE, ADMIN)
